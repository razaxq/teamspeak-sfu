# TS6 Native SFU Lab

让未修改的 TeamSpeak 6 客户端通过自行部署的实验服务端共享屏幕。

**预览版 v0.1.0-preview.1：共享画面已实测可观看；共享声音暂不可用，观看端没有共享音量控件。**

- 服务端仅支持 Linux ARM64（aarch64）及指定镜像版本，暂不支持 x86_64。
- 实测客户端：Windows TeamSpeak 6.0.0-beta4.1，内部版本号 1779880475。
- 通过本项目的服务端扩展、原生信令和 mediasoup 转发媒体，客户端保持原版。
- 部署会创建独立 TeamSpeak 实验服务端；不是给任意现有服务器填写 Endpoint 就能使用。
- 属于社区实验项目，非 TeamSpeak 官方产品。尚未完成长期稳定性、大规模使用及其他版本兼容验证。

从 **[自行部署指南](docs/SELFHOST.md)** 开始；版本状态见 [发布说明](RELEASE_NOTES.md)。
